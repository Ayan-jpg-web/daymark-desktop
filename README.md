# Daymark Desktop

A local-first Windows x64 widget app built on Rainmeter 4.5.28. Display a clock, system stats, notes and optional weather at the same time. The gallery, clock, notes and stats work offline; live weather is opt-in.

[Complete, verified project source ZIP](https://backend.composio.dev/api/v3/sl/IKfr4UWB3k) · SHA-256: `d76582ce5c776f2f460edc5e5ffe73d41f450b2f4fa6b5d7f7172c464af8ec75`.

The source includes the native launcher, editable skins, Windows build script, offline example skin, per-user installer project, GPL license and the pinned [Rainmeter engine](https://github.com/rainmeter/rainmeter/tree/cbd528813fa72fd48fb946c0e994367ed1aca415). On Windows, install the developer prerequisites documented in the source README and run `"Build Windows.cmd" --run`. The preview was exercised under Wine; native Windows QA and signing are pending.
